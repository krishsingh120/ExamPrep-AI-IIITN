# Agents directory
# This directory contains all AI agent implementations.
# Each subdirectory is a separate agent with a clear, single responsibility.
#
# Agents (Phase 3–7):
# - router/       → Query Router: classifies intent and routes to agents
# - retriever/    → Retriever Agent: RAG-based document retrieval
# - weightage/    → PYQ Weightage Agent: deterministic topic frequency analysis
# - predictor/    → Predictor Agent: trend-based question prediction
# - doubt-solver/ → Doubt Solver Agent: conceptual question answering
# - response/     → Response Generator: combines agent outputs, formats response
